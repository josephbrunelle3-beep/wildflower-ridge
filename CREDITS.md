# Credits

Wildflower Ridge is a personal, non-commercial project.

## Art

### Horses

**Horse Sprite With Rider Asset Pack** by **onfe** —
https://onfe.itch.io/horse-sprite-with-rider-asset-pack

Free to use personally or commercially with credit; editing is permitted. Only the two
sheets the game actually uses are included here (`public/assets/sprites/horse-base.png`
and `horse-tacked.png`, both the brown horse), not the pack as a whole.

The pack's "ridden" sheets are deliberately not used: onfe draws the rider as an
unclothed base for the developer to paint over, so Wildflower Ridge uses the riderless
saddled horse and draws its own rider on top.

### Everything else

Tiles, characters, hotbar icons and the ranch map are generated in code at boot
(`src/gfx/PlaceholderTextures.ts`, `src/gfx/RanchMap.ts`) and are original to this project.

Asset packs considered for a later art pass:

- **Sprout Lands Asset Pack** and **Sprout Lands UI Pack** by Cup Nooble
  (https://cupnooble.itch.io/sprout-lands-asset-pack) — free tier: non-commercial use only,
  no redistribution. Credit: Cup Nooble.
